# Security

Please report security problems privately, through [GitHub's private vulnerability reporting](https://github.com/ptmorris05/ecfr-md/security/advisories/new), not in a public issue. You'll get a reply within a week.

Only the latest release is supported.

Things worth reporting include anything that lets a crafted eCFR or GovInfo response, saved file or configuration value write outside the chosen folder, run code, or reach the local web or MCP server from another machine when it is bound to localhost.
